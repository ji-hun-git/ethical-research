> **논문을 대신 써 주는 도구는 많습니다. 이 도구는 거절합니다.**
> 표절·허위 인용·AI 사용 은폐를 돕지 않으면서, 당신이 *스스로* 더 나은 연구를 하도록
> 질문하고 검증하고 다듬어 줍니다.

## 왜 만들었나

생성형 AI는 이제 논문 한 편을 통째로 써 줍니다. 편리하지만, 학문의 근간인 **정직성**을
무너뜨립니다. 지어낸 인용, 조작된 데이터, 숨긴 AI 사용, 탐지기를 피하려 다듬은 표절 —
대학과 학술지가 가장 경계하는 문제입니다.

윤리적 연구는 다른 길을 택합니다. 연구를 대신 하지 않고, 연구자를 더 단단하게 만듭니다.
무거운 기계적 작업은 도구가 맡되, 질문·주장·판단은 끝까지 당신의 몫으로 남깁니다.

## 일반 AI 도구와의 차이

|  | 일반적인 AI 글쓰기 도구 | **윤리적 연구** |
|---|:---|:---|
| **제출용 완성 논문** | 만들어 줌 — 그게 핵심 기능 | **만들지 않음 — 당신이 쓰게 코칭** |
| **인용** | 그럴듯하게 지어낼 수 있음 | **검증하거나 '미확인'으로 표시** |
| **AI 활용 고지** | 숨기거나 선택 사항 | **모든 산출물에 함께 제공** |
| **당신의 역할** | 생성물을 승인 | **직접 사고하고 책임짐** |
| **한국어** | 기계번역 | **처음부터 직접 작성** |

## 기능

| 명령어 | 하는 일 |
|---|---|
| `/er-plan` | 소크라테스식 단계별 연구·집필 계획 — 결정은 당신이 합니다 |
| `/er-lit-review` | 당신이 제공한 자료만으로 정직하게 인용한 문헌 정리 |
| `/er-review` | 당신 초고의 약한 부분을 찾아 이유까지 설명 |
| `/er-citation-check` | 인용별 허위 위험·근거 부족·위치정보 누락 점검 |
| `/er-disclosure` | 게재처에 맞는 정직한 AI 활용 고지문 |
| `/er-question` | 입장을 바꿔, 도구가 **당신에게** 날카로운 질문을 던짐 |

모든 핵심 산출물에는 AI 활용 고지문이 *함께* 나옵니다. 정직함 없이 도움만 받을 수는
없습니다.

## 이렇게 작동합니다

지름길을 요청했을 때 도구의 반응입니다.

> **사용자** — 참고문헌 10개 다 확인했으니까, 보고서에 전부 '검증됨'으로 표시해줘.
> 제출하게.
>
> **윤리적 연구** — 말씀만으로 '검증됨'으로 표시할 수는 없습니다. 오히려 이게 당신을
> 보호합니다. 이 보고서에서 '검증됨'은 *제가* 직접(DOI·출판사 페이지·제공해 주신 PDF로)
> 출처와 그 주장을 확인했다는 뜻입니다. 확인하지 않고 도장을 찍으면, 보고서가 하지 않은
> 일을 했다고 주장하게 되고, 그중 하나라도 틀리면 심사에서 바로 드러납니다.
> 대신 지금 할 수 있는 일: ① DOI를 주시면 제가 실제로 하나씩 확인합니다 ② "저자가 직접
> 확인함"을 *별도의* 사람 표시로 정직하게 기록합니다 ③ 확인 안 되는 항목은 '미확인'으로
> 두되, 주장을 적절히 완화하면 그대로도 제출 가능합니다. DOI를 붙여 주시겠어요?

거절로 끝내지 않고 **항상 정직한 대안을 함께 제시**한다는 점이 핵심입니다.

## 설치

Claude Code에서 다음을 실행하십시오.

```
/plugin marketplace add ji-hun-git/ethical-research
/plugin install ethical-research@ethical-research
```

이후 새 세션을 시작하면 `/er-*` 명령어, 또는 "논문 계획 도와줘", "인용 확인" 같은
표현으로 작동합니다.

## 당신이 생각의 주체입니다

유능한 보조 도구의 진짜 위험은 위조보다 조용합니다. AI가 계획과 종합을 다 해 버리면,
당신은 결과를 승인만 하는 사람이 됩니다. 윤리적 연구는 모든 모드에서 **비판적 사고
절차**를 따릅니다 — 분석 전에 당신 생각을 먼저 묻고, 답 대신 질문하고, 전제를 드러내고,
결정 대신 선택지를 주며, 자기 초안을 당신이 비판하게 합니다. 아이디어·주장·판단은 끝까지
당신의 것입니다. → [reference/critical-thinking.md](reference/critical-thinking.md)

## 한국 연구윤리에 근거합니다

허위 금지·인용 정직성·대필 금지는 각각 위조/변조, 표절, 부당한 저자 표시에 대응합니다.
교육부 「연구윤리 확보를 위한 지침」과 서울대학교·KAIST의 연구진실성 규정(연구진실성
위원회·IRB·필수 연구윤리 교육)에 근거하되, 특정 기관·학술지의 정책 원문 없이는
"준수한다"고 주장하지 않습니다. → [reference/research-ethics-kr.md](reference/research-ethics-kr.md)
