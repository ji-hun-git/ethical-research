# 윤리적 연구 · Ethical Research

*한국어·영어 학술 연구윤리 코파일럿 (Claude Code 스킬).*

> 대신 써 주지 않는다. 사용자가 더 정직한 연구자가 되도록 돕는다.

윤리적 연구는 한국어와 영어로 연구하는 연구자·학생이 학술 작업을 **계획하고,
검토하고, 검증하고, 다듬는** 일을 돕는 Claude Code 스킬입니다. 다만 대신 써 주거나,
출처를 지어내거나, AI 사용 사실을 숨기거나, 표절·탐지기 회피를 돕지는 않습니다.

이 도구의 입장은 단순합니다. 좋은 연구 도구는 사용자를 대체하고 흔적을 지우는 것이
아니라, 사용자가 **더 정직하고 더 나은 연구자**가 되도록 돕는 것이어야 합니다.

**언어:** 한국어 · English · [English README](README.md)
**상태:** v0.1 — 실험 단계. 법률·학사·기관 정책에 대한 조언이 아닙니다.
**라이선스:** [MIT](LICENSE) — 공개이며 상업적 이용도 자유롭습니다.

## 무엇을 하는가 (v0.1)

윤리적 연구는 의도적으로 작고 안전한 기능만 제공합니다. **논문 전체를 대신 써 주는
기능은 없습니다.** 그것이 핵심입니다.

| 명령어 | 기능 |
|---|---|
| `/er-plan` | 소크라테스식 단계별 연구·집필 계획. 결정을 돕되, 대신 결정하지 않습니다. |
| `/er-lit-review` | 사용자가 **직접 제공한** 자료를 정직하게 인용한 주석 문헌 정리. |
| `/er-review` | 사용자가 쓴 초고에 대한 솔직한 비평. 약한 부분을 찾아 이유를 설명합니다. |
| `/er-citation-check` | 인용을 하나씩 검토해 허위 위험, 근거 없는 주장, 위치정보 누락을 표시합니다. |
| `/er-disclosure` | 게재처에 맞는 정직한 AI 활용 고지문 초안을 작성합니다. |

모든 핵심 산출물에는 **AI 활용 고지문이 함께** 제공됩니다. 정직함 없이 도움만 받을
수는 없습니다.

## 하지 않는 일

대필 거부 · 허위 인용·데이터·승인 거부 · AI 탐지기 회피 거부 · 표절 세탁 거부 ·
읽지 않은 자료를 읽은 척하지 않음. 전체 약속과 "거부 → 유용한 대안" 표는
**[윤리적 연구 헌장](ETHICS.md)** 을 참고하십시오.

## 왜 한국어·영어인가

대부분의 학술 AI 도구는 한국어를 번역 대상으로만 취급합니다. 영어로 쓰고 기계번역으로
내보내는 방식입니다. 윤리적 연구는 한국어를 **처음부터 작성하는 언어**로 다룹니다.
산출물은 실제 학술 한국어의 문체(문어체 평서형, 적절한 완곡 표현과 논증 연결어)를
따르며, 인용과 고유명사는 번역하지 않고, 요청 시 한국어·영어를 나란히 제시할 수
있습니다. 자세한 내용은
[reference/korean-academic-register.md](reference/korean-academic-register.md)
와 [reference/korean-glossary.md](reference/korean-glossary.md) 를 보십시오.

## 설치 (Claude Code)

윤리적 연구는 Claude Code 플러그인입니다. 이 저장소를 로컬 플러그인 마켓플레이스로
등록한 뒤 `ethical-research` 플러그인을 활성화하십시오. 활성화하면 "논문 계획 도와줘 /
인용 확인 / help me plan my paper" 같은 표현이나 위의 `/er-*` 명령어로 스킬이
작동합니다.

## 출처와 인용

윤리적 연구는 독립적으로, 클린룸 방식으로 작성된 작업물입니다(MIT 라이선스). 학술
연구 코파일럿이라는 일반적 범주에서 **아이디어**를 빌려 왔으며, 그 사실을 분명히
밝힙니다. **[ACKNOWLEDGMENTS.md](ACKNOWLEDGMENTS.md)** 를 참고하십시오. 사용자에게
요구하는 인용 기준을 우리 자신에게도 적용하는 것은 곁다리가 아니라 이 프로젝트의
핵심입니다.

## 끝이 아니라 시작입니다

윤리적 연구는 계속 발전하는 프로젝트입니다. 더 나은 안전장치, 더 정확한 한국어 학술
관행, 더 나은 연구윤리 전략에 대한 제안을 이슈와 풀 리퀘스트로 환영합니다. AI와
연구윤리에 관한 최종 결론을 자처하지 않습니다. 다만 공개적으로, 바르게 해내려 노력할
뿐입니다.
